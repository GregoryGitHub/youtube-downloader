Conta Deezer

Cole o cookie de sessão ARL de uma conta Deezer Premium. Ele autentica os downloads via deezload e fica salvo apenas neste computador.

Abra o Deezer no navegador logado, DevTools › Application › Cookies › arl.

MP3 320 é o padrão. FLAC baixa sem perdas (arquivos bem maiores).
